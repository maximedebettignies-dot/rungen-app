Le principe

Deux espaces qui ne se croisent jamais

Un compte appartient à un espace le jour de sa création, et n’en change plus jamais. C’est ce qui permet de garantir qu’un adulte inscrit librement sur l’application ne pourra jamais atteindre un élève.

Espace public

15 ans minimum

  • Inscription libre avec un compte Google ou Apple
  • Visibilité au choix : publique, amis, ou privée
  • Ne voit jamais un membre RUNGEN, nulle part

Cloison
étanche

Appliquée par la base de données, pas seulement par l’application

Espace RUNGEN

11 ans minimum

  • Accès uniquement par code individuel, lié à une autorisation parentale signée
  • Profil privé tant que l’élève est mineur
  • Visible des autres élèves, de ses profs d’EPS et de l’administrateur

Dans les classements publics, un jeune RUNGEN apparaîtra sous la mention anonyme « Athlète RUNGEN », sans aucune interaction possible avec le grand public.

En attente

Le code est imprimé mais le papier signé n’est pas revenu. L’élève qui le saisit est refusé.

Actif

L’administrateur a touché « Autorisation reçue » sur son téléphone. Le compte peut être créé.

Utilisé

Le code a servi. Il est consommé définitivement et ne peut plus créer d’autre compte.

Code perdu ? L’ancien est désactivé et un nouveau est généré. Accord parental retiré ? Le code retrouvé sur le papier permet de supprimer le compte correspondant.

Côté professeur

Ce qu’un prof d’EPS voit, et ne voit pas

Un compte encadrant est créé avec son propre code, doit être majeur, et exige une double authentification à chaque session avant d’avoir le moindre pouvoir.

Les élèves de son établissement

Les adhésions de son collège ou lycée, classe par classe. Pseudos et sports, jamais les dates de naissance.

Les codes de son établissement

L’état de chaque code de ses classes : en attente, actif, utilisé ou désactivé.

Pas les autres établissements

Aucun élève, aucun code, aucune classe d’un autre collège. La limite est posée en base, pas dans l’écran.

Pas le support

Les messages que les élèves envoient à l’association ne sont lisibles que par l’administrateur.

Garanties

Les règles qu’on ne peut pas contourner

Chacune est appliquée par la base de données elle-même. L’application ne fait que les refléter : même une version modifiée de l’app ne pourrait pas passer outre.

  • ✓
    Un mineur est toujours en profil privé.Le réglage de visibilité est verrouillé jusqu’à 18 ans. Il n’apparaît dans aucune recherche.
  • ✓
    La date de naissance n’est lisible que par son propriétaire.Elle sert à calculer l’âge, et n’est jamais exposée aux autres utilisateurs. Elle n’est pas modifiable après l’inscription.
  • ✓
    Aucune donnée de santé.Ni poids, ni fréquence cardiaque. Le projet n’en collecte pas, y compris pour les adultes.
  • ✓
    Les messages de support sont définitifs.Ni l’élève ni l’administrateur ne peuvent modifier ou supprimer un message envoyé. L’administrateur ne peut que répondre.
  • ✓
    Le compte est supprimable depuis l’application.Par l’élève lui-même, ou par l’administrateur en cas de retrait de l’accord parental. Suppression complète, en cascade.
  • ✓
    Aucun ciblage publicitaire.Les futurs challenges de partenaires excluront alcool, jeux d’argent, boissons énergisantes et malbouffe, avec un interrupteur « visible par les jeunes » par challenge.

Forme et prédictions, amis et fil, clubs et challenges, partage. À venir.
