La démo

Les écrans du bloc 1, navigables pour de vrai. Même palette, mêmes textes et mêmes règles d’âge que l’application. Rien n’est envoyé nulle part : tout se joue dans cette page.

À montrer en priorité

Chaque bouton place la démo au bon endroit.

Codes d’essai

Un code fait 10 caractères et n’utilise ni O, ni I, ni 0, ni 1 — pour qu’on ne se trompe pas en le recopiant depuis le papier.

CodeCe qui se passe
KHTP4R9MDXActif : l’autorisation signée est revenue, le compte peut être créé.
BCDF7GHJ2KEn attente : imprimé, mais le papier n’est pas encore revenu.
MNPQ3RST4VDéjà utilisé : un compte existe, le code est consommé.
n’importe quoiInvalide.

Ce que la démo ne fait pas

Pas de connexion Google ou Apple réelle : elle passe par le système du téléphone et n’existe pas dans un navigateur. Pas de base de données non plus — dans l’application, ce sont les règles en base qui refusent un âge insuffisant ou un code déjà utilisé, pas l’écran. Ici, l’écran les rejoue pour la démonstration.
